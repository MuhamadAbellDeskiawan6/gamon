URL Webhook

Tempel URL ini di dashboard Digiflazz (menu Atur Koneksi → API → Webhook), lalu isi secret yang sama dengan DIGIFLAZZ_WEBHOOK_SECRET.

Environment Variable (Vercel)

Panel otomatis berjalan dalam mode DEMO selama username / API key belum diisi.

  • DIGIFLAZZ_USERNAME — username API Digiflazz
  • DIGIFLAZZ_API_KEY — development key dulu, production key setelah verifikasi
  • DIGIFLAZZ_WEBHOOK_SECRET — string acak, sama dengan di Digiflazz
  • DIGIFLAZZ_TESTING — true untuk uji coba
  • TOPUP_MARGIN_PERCENT / TOPUP_MARGIN_MIN — margin harga jual
  • DIGIFLAZZ_BASE_URL & RELAY_KEY — hanya jika memakai relay IP tetap (opsional)
